# Task template

Shape for a groomed backlog item and for the matching sections in a handoff. PM fills every section before implementation.

## Goal

One or two sentences on what should be true when this is done.

## Acceptance criteria

- [ ] A statement you can check by looking at the result
- [ ] One line per case, including the awkward ones

## Out of scope

- Something that does not belong in this task, moved to #N

## Constraints

- Files this should stay inside
- Libraries to use
- Guidelines to follow
